    The LLM was not good at detecting bugs that were also reported as GitHub issues.
For the summarizer microservice the LLM would often not follow the directions of the prompt to give back one JSON so it was difficult to parse the response. For the bug finder service, the LLM was better at returning correctly formatted Issues but would sometimes not catch bugs in the code. The issue comparator service was not good at finding common issues given two lists of issues. It would be able to parse the input but would not reason correctly and not give back any common issues. When manually comparing the two lists, a couple of issues were common. In conclusion, we think that the LLM could detect some bugs also reported as GitHub issues but not well.
